# 飞机大战 · Plane War

一个用纯 HTML5 Canvas 实现的网页版「飞机大战」小游戏，**零依赖、无需任何图片/音频素材**，图形全部由代码绘制，音效由 Web Audio 实时合成。直接用浏览器打开即可游玩。

## 🎮 在线试玩

直接双击打开 `index.html`，或在项目目录下启动一个本地静态服务器：

```bash
# 任选其一
python -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

> 建议用本地服务器方式打开，部分浏览器对 `file://` 下的音频/特性有限制。

## 🕹️ 操作说明

| 操作 | 按键 / 方式 |
| --- | --- |
| 移动战机 | 鼠标移动 / 触屏拖动，或 方向键 / `WASD` |
| 开火 | 自动开火（无需操作） |
| 释放炸弹 | `空格键` 或 点击/触摸屏幕（清屏并秒杀全部敌机） |
| 暂停 / 继续 | `P` 键 或 右上角 ⏸ 按钮 |
| 音效开关 | 右上角 🔊 按钮 |

## ✨ 玩法特性

- **三种敌机**：小型机（绿，1血）、中型机（黄，3血，会射击）、大型机（红，10血，火力强、必掉道具）。
- **火力升级**：吃到蓝色 `P` 道具，子弹从单发 → 双发 → 三向散射；被击中会掉一级。
- **炸弹道具**：橙色 `B` 道具，吃到立即清屏。
- **难度递增**：随时间推移，敌机刷新更快、移动更猛、大型机更多。
- **生命与复活**：3 条命，被撞或中弹扣 1 命并短暂无敌闪烁。
- **最高分记录**：通过 `localStorage` 本地保存历史最高分。
- **打击感**：爆炸粒子、命中闪白、尾焰、星空滚动背景、合成音效。

## 🛠️ 技术要点

- 纯原生 JavaScript + Canvas 2D，单文件主循环 `requestAnimationFrame` + 基于 delta time 的更新。
- 所有飞机、子弹、道具均为矢量绘制，AABB 矩形碰撞检测。
- Web Audio API 用振荡器实时合成开火/爆炸/拾取/炸弹等音效，无外部资源。
